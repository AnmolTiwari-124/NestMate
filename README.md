RoomSync

A full-stack AI-powered roommate and PG/flatmate matching platform built using the MERN stack (MongoDB, Express.js, React, Node.js). RoomSync helps users discover compatible roommates, shared accommodations, and rental spaces based on lifestyle preferences, budget, location, and personality compatibility—providing a smarter and more personalized living experience.

🔥 Features

✅ JWT-based Authentication
🏠 Create & Manage Room/PG Listings
🤖 AI-based Roommate Compatibility Matching
❤️ Save & Bookmark Listings
💬 Real-time Chat with Socket.io
👥 User Profile & Preference Management
🔍 Smart Search & Advanced Filters
📍 Location-based Room Discovery
📱 Fully Responsive Modern UI

🚀 Getting Started
1. Clone the Repository
git clone https://github.com/your-username/RoomSync.git
cd RoomSync
📦 Frontend Setup
cd frontend
npm install
npm run dev

🔑 Environment Variables

Create a .env file inside the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
💡 Usage
Register or log in securely
Create and browse room/PG listings
Find compatible roommates using AI matching
Apply smart filters based on budget, lifestyle, food preference, and location
Chat with potential roommates in real time
Manage profile and accommodation preferences
